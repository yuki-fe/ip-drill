ITパスポートの略語クイズと早見表（142語）

ITパスポート試験には、KPI・SLA・DNS のようなアルファベットの略語がたくさん出ます。略語は、元の英語（正式名）と一緒に覚えると忘れにくくなります。

CADComputer Aided Designコンピュータを使って、製品や建物などの設計図を作ること。

DXDigital Transformationデジタルトランスフォーメーションのこと。データとデジタル技術を使って、製品・サービスやビジネスのやり方、組織そのものを変革し、競争で優位に立つこと。
ECElectronic Commerce電子商取引のこと。インターネットなどのネットワークを使って、商品やサービスを売買すること。
EDIElectronic Data Interchange電子データ交換のこと。企業の間で、受発注などの取引のデータを決まった形式でやり取りすること。
ERPEnterprise Resource Planning企業資源計画のこと。会計・人事・生産・販売などの基幹業務の情報を1つにまとめて管理し、経営資源を有効に使う手法。
FAFactory Automation工場の生産工程を、コンピュータやロボットで自動化すること。
GDPRGeneral Data Protection RegulationEU（欧州連合）の一般データ保護規則。EUの中の個人データの扱いを定めたもので、EUの外の企業にも適用されることがある。
GPSGlobal Positioning System人工衛星からの電波を使って、地球上の現在の位置を調べる仕組み。
IaaSInfrastructure as a Serviceサーバ・ストレージ・ネットワークなどの設備を、インターネットを通じて提供する形態。
IEEEInstitute of Electrical and Electronics Engineers米国に本部がある電気・電子工学の学会。無線LAN（IEEE 802.11）などの規格を作っている。
IRInvestor Relations投資家向け広報のこと。株主や投資家に向けて、経営や財務の情報を発信する活動。
ISOInternational Organization for Standardization国際標準化機構のこと。工業や技術などの国際規格を作る組織。
JISJapanese Industrial Standards日本産業規格のこと。日本の産業製品やデータ、サービスなどに関する国の規格。

KPIKey Performance Indicator重要業績評価指標のこと。最終的な目標（KGI）に向けて、途中の進み具合を測る数値。
M&AMergers and Acquisitions企業の合併（Mergers）と買収（Acquisitions）のこと。他社の事業や技術を短い期間で手に入れられる。
MaaSMobility as a Service電車・バス・タクシーなどのさまざまな交通手段を1つのサービスとしてまとめ、検索・予約・支払いを一度にできるようにすること。
MBOManagement Buyout経営陣が自分の会社の株式を買い取り、経営権を手に入れること。マネジメントバイアウトとも呼ぶ。
MOTManagement Of Technology技術経営のこと。技術を事業の成果に結び付けるための経営の考え方。
MRPMaterial Requirements Planning資材所要量計画のこと。生産計画から、必要な部品や材料の量と時期を計算し、発注を管理する手法。
NDANon-Disclosure Agreement秘密保持契約のこと。取引の中で知った相手の秘密の情報を、外に漏らさないことを約束する契約。
O2OOnline to OfflineWebやアプリ（オンライン）から、実際の店舗（オフライン）へ客を呼び込む取組み。
OEMOriginal Equipment Manufacturing相手先のブランドで製品を製造すること。他社のブランド名で売られる製品を作る。
Off-JTOff the Job Training職場を離れて、研修やセミナーなどで行う教育。
OJTOn the Job Training職場で実際の仕事をしながら、上司や先輩が仕事に必要な知識や技能を教える教育方法。
PaaSPlatform as a Serviceアプリケーションを動かすための基盤（OSやデータベースなど）を、インターネットを通じて提供する形態。
PoCProof of Concept概念実証のこと。新しいアイデアや技術が実際に実現できるかを、試作などで確かめること。
POSシステムPoint Of Sale商品が売れたときに、何がいつ何個売れたかの情報をその場で集めて管理する仕組み。
PPMProduct Portfolio Management市場の成長率と市場の占有率の2つの軸で、事業を「花形・金のなる木・問題児・負け犬」に分け、経営資源の配分を考える手法。
RFIRequest For Information情報提供依頼書のこと。システムを発注する前に、ベンダに技術や製品の情報の提供を求める文書。
RFIDRadio Frequency Identification電波を使って、ICタグの情報を触れずに読み書きする技術。商品の管理などに使う。
RFPRequest For Proposal提案依頼書のこと。発注する側がシステムの要件などを示し、ベンダに具体的な提案を求める文書。
ROAReturn On Assets総資産利益率のこと。会社が持つすべての資産を使って、どれだけ利益を上げたかを示す指標。
ROEReturn On Equity自己資本利益率のこと。株主が出したお金（自己資本）に対して、どれだけ利益を上げたかを示す指標。
ROIReturn On Investment投資利益率のこと。投資した金額に対して、どれだけの利益が得られたかを示す指標。
RPARobotic Process Automationこれまで人がパソコンで行っていた定型的な作業を、ソフトウェアのロボットで自動化すること。
SaaSSoftware as a Serviceインターネットを通じて、ソフトウェア（アプリケーション）の機能をサービスとして提供する形態。
SCMSupply Chain Management供給連鎖管理のこと。原材料の調達から生産・物流・販売までを、企業の枠を超えて全体で管理する手法。
SDGsSustainable Development Goals国連で採択された、2030年までに達成を目指す17の「持続可能な開発目標」。
SEOSearch Engine Optimization検索エンジン最適化のこと。検索結果で自分のWebサイトが上のほうに表示されるように工夫すること。
SFASales Force Automation営業支援システムのこと。営業担当者の活動や商談の情報を共有・管理して、営業を効率化する。
SOAService Oriented Architectureシステムの機能を「サービス」という部品として作り、それらを組み合わせてシステムを作る考え方。
TOBTake Over Bid株式公開買付けのこと。買う期間・価格・株数を公表して、市場の外で株主から株式を買い集める方法。
TQMTotal Quality Management総合的品質管理のこと。品質の向上を、組織全体で継続して進める経営手法。
W3CWorld Wide Web ConsortiumWebで使う技術（HTMLなど）の標準を作る国際的な団体。

略語正式名意味
AIArtificial Intelligence人工知能のこと。人間の知的な働き（学習・推論・判断など）を、コンピュータで実現する技術。
APIApplication Programming Interfaceソフトウェアの機能やデータを、外部の別のプログラムから呼び出して使うための窓口（取決め）。
ARAugmented Reality拡張現実のこと。現実の風景に、コンピュータで作った情報や映像を重ねて表示する技術。
BCCBlind Carbon Copy電子メールで、他の受信者にアドレスを知られずに、同じメールを送るときに使う欄。

bpsbits per second通信の速さの単位。1秒間に送れるビットの数を表す。
CCCarbon Copy電子メールで、本来の宛先以外の人にも同じメールを送るときに使う欄。受け取った人全員に、そのアドレスが見える。
CPUCentral Processing Unit中央処理装置のこと。プログラムの命令を読み取り、計算や制御を行うコンピュータの中心となる装置。
CSIRTComputer Security Incident Response Teamセキュリティの事故（インシデント）が起きたときに、対応にあたる組織の中のチーム。
CSSCascading Style SheetsWebページの文字の大きさや色、配置などの見た目を指定するための言語。
CSVComma Separated Valuesデータを「,」（カンマ）で区切って並べたテキストの形式。表計算ソフトとのデータのやり取りによく使う。
CUICharacter User Interfaceキーボードで文字のコマンドを入力して操作する画面の仕組み。
DBMSDatabase Management Systemデータベース管理システムのこと。データベースを作り、データの追加・検索・更新などを管理するソフトウェア。
DDoS攻撃Distributed Denial of Service多数の端末から一斉にDoS攻撃を行う攻撃。
DHCPDynamic Host Configuration Protocolネットワークにつないだ機器に、IPアドレスなどの設定を自動で割り当てるプロトコル。
DMZDeMilitarized Zone外部のネットワークと内部のネットワークの間に設ける、緩衝地帯のようなネットワーク。外部に公開するWebサーバなどを置く。
DNSDomain Name System「www.example.jp」のようなドメイン名と、IPアドレスを対応付ける仕組み。
DoS攻撃Denial of Serviceサーバに大量のデータを送りつけるなどして負荷をかけ、サービスを止めてしまう攻撃。
DRAMDynamic Random Access Memoryメインメモリに使われるRAM。安くて容量を大きくしやすいが、内容を保つために定期的な書き直し（リフレッシュ）が必要。
FTPFile Transfer Protocolネットワークで、ファイルを送ったり受け取ったりするためのプロトコル。
GIFGraphics Interchange Format256色までの静止画の形式。簡単なアニメーションも表現できる。
GPUGraphics Processing Unit画像を描く処理を得意とするプロセッサ。大量の計算を同時に行えるので、AIの学習にも使われる。
GUIGraphical User Interfaceアイコンやボタンなどを画面に表示し、マウスや指で操作できるようにした画面の仕組み。
HDDHard Disk Drive磁気ディスクを回転させてデータを読み書きする補助記憶装置。容量あたりの値段が安い。
HDMIHigh-Definition Multimedia Interface映像と音声を、1本のケーブルでまとめて送るための規格。テレビやディスプレイの接続に使う。
HTMLHyperText Markup LanguageWebページを作るためのマークアップ言語。見出しや段落、リンクなどをタグで示す。
HTTPHyperText Transfer ProtocolWebブラウザとWebサーバの間で、Webページのデータをやり取りするためのプロトコル。
HTTPSHyperText Transfer Protocol SecureHTTPの通信を、TLSで暗号化したもの。
IDSIntrusion Detection Systemネットワークやサーバへの不正な侵入を見つけて、管理者に知らせる仕組み。
IMAPInternet Message Access Protocolメールをサーバに置いたまま、読んだり管理したりするためのプロトコル。複数の端末で同じメールを見られる。
IoTInternet of Thingsモノのインターネットのこと。家電や車などのさまざまなモノがインターネットにつながり、情報をやり取りする仕組み。
IPSIntrusion Prevention System不正な侵入を見つけて知らせるだけでなく、その通信を自動で止める仕組み。
ISMSInformation Security Management System情報セキュリティマネジメントシステムのこと。組織が情報セキュリティを継続して管理・改善するための仕組み。
JPEGJoint Photographic Experts Group写真などのカラーの静止画を圧縮して保存するための形式。圧縮すると画質が少し落ちる（非可逆圧縮）。
JSONJavaScript Object Notationデータをやり取りするための、文字で書かれた軽いデータ形式。JavaScriptの書き方がもとになっている。
LANLocal Area Network会社や家庭の中など、限られた範囲で使うネットワーク。
LPWALow Power Wide Area少ない電力で、広い範囲の通信ができる無線通信の技術の総称。IoTで使われる。
MDMMobile Device Management会社が社員に配ったスマートフォンなどの端末を、まとめて管理する仕組み。紛失したときに、遠隔でデータを消すこともできる。
MIMEMultipurpose Internet Mail Extensions電子メールで、画像などの文字以外のデータや、日本語などを送れるようにする仕組み。
MP3MPEG-1 Audio Layer-3音声を圧縮して保存するための形式。
MPEGMoving Picture Experts Group動画を圧縮して保存するための形式。
MTBFMean Time Between Failures平均故障間隔のこと。故障が直ってから次に故障するまでの、正常に動いている時間の平均。
MTTRMean Time To Repair平均修復時間のこと。故障してから直るまでにかかる時間の平均。
MVNOMobile Virtual Network Operator自分では通信回線の設備を持たず、他の通信事業者から借りて通信サービスを提供する事業者。格安SIMなど。
NASNetwork Attached Storageネットワークに直接つないで、複数のコンピュータからファイルを共有できる記憶装置。
NATNetwork Address TranslationプライベートIPアドレスとグローバルIPアドレスを変換して、LANの中の機器がインターネットを使えるようにする仕組み。
NFCNear Field Communication10cm程度のごく近い距離で、機器をかざして無線通信を行う規格。交通系ICカードやスマートフォンでの支払いに使う。
NTPNetwork Time Protocolネットワークにつながる機器の時刻を、正しい時刻に合わせるためのプロトコル。
OSOperating Systemオペレーティングシステムのこと。コンピュータ全体を管理し、アプリケーションが動くための基盤となる基本ソフトウェア。Windows・macOS・Linux・Android・iOSなど。
OSSOpen Source Softwareオープンソースソフトウェアのこと。ソースコードが公開され、決められた条件のもとで、誰でも使用・改変・再配布できるソフトウェア。
PDFPortable Document Formatパソコンの機種や環境に関係なく、同じ見た目で文書を表示・印刷できるファイルの形式。
PKIPublic Key Infrastructure公開鍵基盤のこと。認証局が発行する電子証明書を使って、公開鍵の持ち主を保証する仕組み。
PNGPortable Network Graphics画質を落とさずに圧縮できる静止画の形式。透明な部分も表現できる。
POP3Post Office Protocol version 3メールサーバから、メールを自分の端末に受信するためのプロトコル。受け取ったメールは端末に保存される。
RAIDRedundant Arrays of Independent Disks複数のHDDやSSDを組み合わせて、1台の装置のように使う技術。速さや信頼性を高める。
RAMRandom Access Memory読み書きができるメモリ。電源を切ると内容が消える（揮発性）。
ROMRead Only Memory読み出し専用のメモリ。電源を切っても内容が消えない（不揮発性）。
SMTPSimple Mail Transfer Protocol電子メールを送信したり、メールサーバの間で転送したりするためのプロトコル。
SOCSecurity Operation Centerネットワークや機器を24時間監視し、サイバー攻撃を見つけて分析する組織。
SRAMStatic Random Access Memoryキャッシュメモリに使われるRAM。高速だが値段が高い。リフレッシュは要らない。
SSDSolid State Driveフラッシュメモリを使った補助記憶装置。HDDより高速で、衝撃に強く、音もしない。
SSIDService Set Identifier無線LANのアクセスポイントを見分けるための名前。
TCOTotal Cost of Ownership総所有費用のこと。システムの導入費用だけでなく、運用や保守、教育などにかかる費用も含めた総額。
TLSTransport Layer Securityインターネット上の通信を暗号化し、通信の相手を確かめるためのプロトコル。HTTPSで使われる。SSLの後継。
URLUniform Resource Locatorインターネット上のWebページなどの場所を示す書き方（例: https://www.example.jp/index.html）。
USBUniversal Serial Busパソコンと周辺機器をつなぐための規格。USB Type-Cなどの形がある。
UXUser Experienceユーザエクスペリエンスのこと。製品やサービスを使ったときに、利用者が得られる体験の全体。
VPNVirtual Private Networkインターネットなどの公共のネットワークの上に、暗号化などで仮想的な専用のネットワークを作る技術。
VRVirtual Reality仮想現実のこと。コンピュータで作った仮想の世界を、実際にその場にいるように体験できる技術。
WAFWeb Application FirewallWebアプリケーションへの通信を調べ、SQLインジェクションなどの攻撃を見つけて防ぐ仕組み。
WANWide Area Network離れた場所のLANどうしなどを、通信事業者の回線を使ってつなぐ、広い範囲のネットワーク。
WPA3Wi-Fi Protected Access 3無線LANの通信を暗号化するためのセキュリティの規格。WPA2の後継。
XMLExtensible Markup Language利用者が独自のタグを決めて、データの意味や構造を表せるマークアップ言語。
