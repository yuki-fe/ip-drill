教師あり学習・教師なし学習・強化学習の違い

機械学習の代表的な3つの方法です。教師あり学習は正解の付いたデータで学び、教師なし学習は正解のないデータから特徴やグループを見つけ、強化学習は試行錯誤して報酬が多くなる行動を学びます。

表で比べる

観点教師あり学習教師なし学習強化学習
使うデータ正解（ラベル）の付いたデータ正解の付いていないデータ行動の結果として得られる報酬
学ぶこと入力から正解を当てるルールデータの特徴やグループ分け報酬が多くなる行動のしかた
例迷惑メールかどうかを見分ける買い物の傾向が似た顧客をグループに分けるゲームやロボットの動かし方を覚える

見分けるポイント

  • 「正解（ラベル）付きのデータ」なら教師あり学習
  • 「正解なし」「グループ分け（クラスタリング）」なら教師なし学習
  • 「報酬」「試行錯誤」なら強化学習

試験での出され方

AI の使い方の例を読んで、どの学習方法にあたるかを選ぶ問題が出ます。正解のデータを用意するための作業（アノテーション）や、学習しすぎて新しいデータに弱くなる過学習もあわせて覚えておきましょう。

それぞれの用語

  • 教師あり学習

    正解（ラベル）の付いたデータを使って学習させる、機械学習の方法。

  • 教師なし学習

    正解の付いていないデータから、データの特徴やグループを見つけ出す、機械学習の方法。

  • 強化学習

    試行錯誤を繰り返し、より多くの報酬が得られる行動を学んでいく、機械学習の方法。
