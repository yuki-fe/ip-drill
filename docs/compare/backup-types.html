フルバックアップ・差分バックアップ・増分バックアップの違い

フルバックアップはすべてのデータを写します。差分バックアップは「最後のフルバックアップから」、増分バックアップは「前回のバックアップから」変わった部分だけを写します。

表で比べる

観点フルバックアップ差分バックアップ増分バックアップ
写すデータすべてのデータ最後のフルバックアップの後に変わったデータ前回のバックアップ（フルでも増分でも）の後に変わったデータ
バックアップにかかる時間長い日がたつほど長くなる短い
元に戻すときに使うものフルバックアップ1つフルバックアップと、最新の差分バックアップフルバックアップと、その後の増分バックアップすべて
元に戻す手間少ない中くらい多い

見分けるポイント

  • 差分は「フルから」、増分は「前回から」が基準
  • バックアップは増分がいちばん速く、元に戻すのは差分のほうが楽
  • 増分は、途中の1つでも欠けると元に戻せなくなる

試験での出され方

「日曜にフルバックアップ、月〜土に差分（または増分）バックアップを取った。木曜に障害が起きたとき、元に戻すのに必要なバックアップはどれか」という問題が出ます。差分なら日曜のフルと水曜の差分、増分なら日曜のフルと月・火・水の増分すべてです。

それぞれの用語

  • フルバックアップ

    すべてのデータを、丸ごと写し取るバックアップ。

  • 差分バックアップ

    最後のフルバックアップの後に変わったデータだけを、写し取るバックアップ。

  • 増分バックアップ

    前回のバックアップ（フルでも増分でも）の後に変わったデータだけを、写し取るバックアップ。
