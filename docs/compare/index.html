似た用語の違いITパスポート試験でまぎらわしい用語 15組

試験では、似た用語の違いがよく問われます。2つ（3つ以上）の用語を表で並べて、どこが違うかを確かめましょう。

  • SaaS・PaaS・IaaSの違い

    どれもインターネットを通じて使うクラウドサービスです。違いは「どこまでを事業者が用意してくれるか」。SaaS はソフトウェアまで、PaaS は動かす基盤まで、IaaS はサーバなどの設備だけを提供します。

  • 請負契約・準委任契約・労働者派遣の違い

    仕事を外部に頼むときの代表的な3つの形です。請負は「仕事の完成」、準委任は「作業をすること」を約束します。労働者派遣だけは、働く人に仕事を頼んだ側（派遣先）が直接指示を出します。

  • 共通鍵暗号方式と公開鍵暗号方式の違い

    共通鍵暗号方式は暗号化と復号に同じ鍵を使い、公開鍵暗号方式は「公開鍵」と「秘密鍵」の2つの鍵を使います。共通鍵は処理が速く、公開鍵は鍵を安全に配りやすいのが特徴です。

  • フルバックアップ・差分バックアップ・増分バックアップの違い

    フルバックアップはすべてのデータを写します。差分バックアップは「最後のフルバックアップから」、増分バックアップは「前回のバックアップから」変わった部分だけを写します。

  • フォールトトレランス・フェールセーフ・フェールソフト・フールプルーフの違い

    どれも故障やミスに備える考え方です。フォールトトレランスは「止めない」、フェールセーフは「安全な側に止める」、フェールソフトは「機能を落として動かし続ける」、フールプルーフは「人の操作ミスを防ぐ」考え方です。

  • ウォーターフォールモデルとアジャイルの違い

    ウォーターフォールモデルは工程を順番に進めて、原則として前に戻らない開発手法です。アジャイルは、短い期間で作ってはリリースすることを繰り返し、変化に合わせて進める開発手法です。

  • ブラックボックステストとホワイトボックステストの違い

    ブラックボックステストはプログラムの中身を見ずに、入力と出力だけで確かめるテストです。ホワイトボックステストはプログラムの中身（処理の流れ）を見て、命令や分岐が正しく動くかを確かめます。

  • KGI・KPI・CSFの違い

    KGI は最終的な目標を数値で表したもの、KPI はその目標に向けた途中の進み具合を測る数値です。CSF は、目標を達成するために特に大事な要因（何に力を入れるか）です。

  • 機密性・完全性・可用性の違い

    情報セキュリティの3要素です。機密性は「許可された人だけが使える」、完全性は「正しく、改ざんされていない」、可用性は「使いたいときに使える」ことを表します。

  • リスク回避・リスク低減・リスク移転・リスク受容の違い

    リスクへの4つの対応です。回避は「やめる」、低減は「小さくする」、移転は「ほかに任せる・分け合う」、受容は「そのまま受け入れる」です。

  • 特許権・実用新案権・意匠権・商標権の違い

    4つとも産業財産権です。特許権は「発明」、実用新案権は「物の形や構造の考案（小発明）」、意匠権は「デザイン」、商標権は「商品やサービスの名前・マーク」を守ります。

  • 教師あり学習・教師なし学習・強化学習の違い

    機械学習の代表的な3つの方法です。教師あり学習は正解の付いたデータで学び、教師なし学習は正解のないデータから特徴やグループを見つけ、強化学習は試行錯誤して報酬が多くなる行動を学びます。

  • 主キーと外部キーの違い

    主キーは、表の中で1つの行を決めるための項目です。外部キーは、ほかの表の主キーを参照する項目で、表と表のつながりを表します。

  • デュアルシステムとデュプレックスシステムの違い

    どちらもシステムを2つ用意して故障に備えます。デュアルシステムは2つで同じ処理を同時に行って結果を照らし合わせ、デュプレックスシステムはふだん1つを使い、故障したら予備に切り替えます。

  • SWOT分析・3C分析・PEST分析の違い

    どれも会社のまわりの状況を整理する分析手法です。SWOT分析は自社の強み・弱みと外部の機会・脅威、3C分析は顧客・競合・自社、PEST分析は政治・経済・社会・技術という大きな環境の変化を見ます。
