マネジメント系・開発の進め方

CMMI

正式名Capability Maturity Model Integration

組織のソフトウェア開発の能力（プロセスの成熟度）を、5つの段階で評価するモデル。

カードで練習する 略語クイズに挑戦

同じ分野の用語

  • 共通フレーム

    ソフトウェアの開発や取引で使う作業の内容や用語を、関係者の間でそろえるための枠組み。

  • リバースエンジニアリング

    既にあるソフトウェアを分析して、仕組みや設計の情報を取り出すこと。

  • DevOps

    開発（Development）と運用（Operations）の担当者が協力し、システムの開発から運用までを素早く進める考え方。

  • リファクタリング

    プログラムの外から見た動きは変えずに、中の構造を分かりやすく整理し直すこと。

  • ペアプログラミング

    2人1組で、1人がプログラムを書き、もう1人がそれを確認しながら一緒に開発するやり方。

  • テスト駆動開発

    プログラムを書く前にテストを作り、そのテストに合格するようにプログラムを書いていく開発のやり方。
