テクノロジ系・ネットワーク

ポート番号

1台のコンピュータの中で、通信の相手となるアプリケーションを見分けるための番号。

カードで練習する 書いて答える問題に挑戦

同じ分野の用語

  • MACアドレス

    ネットワークにつなぐ機器（の通信部品）ごとに、製造のときに割り当てられる番号。

  • HTTP

    WebブラウザとWebサーバの間で、Webページのデータをやり取りするためのプロトコル。

  • URL

    インターネット上のWebページなどの場所を示す書き方（例: https://www.example.jp/index.html）。

  • HTTPS

    HTTPの通信を、TLSで暗号化したもの。

  • ドメイン名

    IPアドレスの代わりに、人が覚えやすいように付けたネットワーク上の名前（例: example.jp）。

  • SMTP

    電子メールを送信したり、メールサーバの間で転送したりするためのプロトコル。
