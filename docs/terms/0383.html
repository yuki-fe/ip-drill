同じ分野の用語

  • プログラム言語

    コンピュータへの命令を書くための言語。Python・Java・C言語など。

  • JavaScript

    Webページに動きを付けるためによく使われるプログラム言語。ブラウザの中で動く。

  • ソート

    データを決まった順番（小さい順・大きい順など）に並べ替えること。整列とも呼ぶ。

  • Java

    オブジェクト指向のプログラム言語。いろいろなOSの上で、同じプログラムを動かしやすい。

  • 二分探索

    整列したデータの真ん中の値と比べて、探す範囲を半分ずつに絞っていく探索の方法。

  • マークアップ言語

    文章の構造や見た目を、タグなどの記号で示すための言語。HTMLやXMLなど。
