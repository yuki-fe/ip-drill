クリティカルパス

作業の流れのうち、最も時間がかかる経路。この経路の上の作業が遅れると、全体が遅れる。

クリティカルパスの求め方（› を押すか、図をタップすると進みます）

  1. 作業をつないだ図（数字は日数）
  2. A → C → E の経路：3 + 2 + 2 = 7日
  3. B → D → E の経路：5 + 4 + 2 = 11日
  4. いちばん長い B → D → E がクリティカルパス（全体は11日）

同じ分野の用語

  • アローダイアグラム

    作業の順番と関係を、矢印と結合点で表した図。PERT図とも呼ぶ。

  • マイルストーン

    プロジェクトの途中に置く、重要な節目となる時点（例: 設計の完了）。

  • ガントチャート

    作業を縦に並べ、横軸の時間に沿って、それぞれの作業の予定や実績を横棒で表した図。

  • EVM

    作業の価値を金額に置き換えて、計画・実績・出来高を比べ、プロジェクトの進み具合とコストを管理する手法。

  • WBS

    プロジェクトの作業を、管理しやすい大きさまで階層的に細かく分けたもの。

  • ファンクションポイント法

    ソフトウェアの機能の数や複雑さをもとに、開発の規模を見積もる方法。
