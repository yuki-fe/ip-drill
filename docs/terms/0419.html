キャッシュメモリ

CPUとメインメモリの間に置く、小さくて高速なメモリ。よく使うデータを置いて、処理を速くする。

キャッシュメモリの働き（› を押すか、図をタップすると進みます）

  1. CPU と主記憶のあいだに、速いキャッシュ
  2. 初めてのデータは、遅い主記憶から読む
  3. 読んだデータを、キャッシュにも置いておく
  4. 2回目からはキャッシュから速く読める（ヒット）

同じ分野の用語

  • 主記憶装置（メインメモリ）

    CPUが直接読み書きする記憶装置。実行中のプログラムやデータを一時的に置く。

  • RAM

    読み書きができるメモリ。電源を切ると内容が消える（揮発性）。

  • GPU

    画像を描く処理を得意とするプロセッサ。大量の計算を同時に行えるので、AIの学習にも使われる。

  • ROM

    読み出し専用のメモリ。電源を切っても内容が消えない（不揮発性）。

  • マルチコアプロセッサ

    1つのCPUの中に、処理を行う中心部分（コア）を複数持つもの。複数の処理を同時に進められる。

  • DRAM

    メインメモリに使われるRAM。安くて容量を大きくしやすいが、内容を保つために定期的な書き直し（リフレッシュ）が必要。
