同じ分野の用語

  • OSS

    オープンソースソフトウェアのこと。ソースコードが公開され、決められた条件のもとで、誰でも使用・改変・再配布できるソフトウェア。

  • コピーレフト

    著作権を持ったまま、改変したものも同じ条件で公開することを求める考え方。GPLなどのライセンスで使われる。

  • 絶対参照

    表計算ソフトで、式を他のセルに写しても、参照するセルの位置が変わらない参照の仕方。「$」を付けて表す。

  • API

    ソフトウェアの機能やデータを、外部の別のプログラムから呼び出して使うための窓口（取決め）。

  • 相対参照

    表計算ソフトで、式を他のセルに写したときに、参照するセルの位置も一緒にずれる参照の仕方。

  • Webブラウザ

    Webページを見るためのソフトウェア。
